# 2. 설계 및 구현 계획

## 사용된 API / 라이브러리 / 프레임워크

웹 서버는 Flask다. `app.py`에서 페이지랑 업로드·병합·프롬프트 API를 다 받는다. 프롬프트 생성은 `prompt_generator.py`에서 OpenAI GPT-4o를 쓰고, 응답을 JSON으로 받는다. 영상 쪽은 FFmpeg/ffprobe로 재인코딩·비율·letterbox·concat을 처리하고 (`merge/merge.py`), 텍스트·이모지 오버레이는 Pillow로 PNG를 그린 뒤 얹는다. API 키는 python-dotenv로 `.env`에서 읽는다.

`requests`는 `app.py`에 import만 있고 쓰는 곳은 없다. google-api, playwright, schedule도 `requirements.txt`에만 남아 있다. 예전에 AI 클리핑이 있을 때는 FastAPI, Whisper, yt-dlp, OpenCV 얼굴 감지도 썼는데 모듈 지우면서 같이 빠졌다.

| 이름 | 어디서 |
|------|--------|
| Flask | `app.py` |
| OpenAI GPT-4o | `prompt_generator.py` |
| FFmpeg / ffprobe | `merge.py` |
| Pillow | `merge.py` 오버레이 |
| python-dotenv | `.env` |

프롬프트는 시스템 프롬프트를 고정해 두고, 모델이 준 문장 뒤에 씹기·장비 비노출·ASMR 오디오 문구를 코드에서 덧붙인다.

## 요청–응답 흐름

**영상 병합**

1. 브라우저가 `POST /api/upload/video`로 MP4를 올리면 `videos/raw/`에 `타임스탬프_원본이름.mp4`로 저장되고, 파일명을 JSON으로 돌려준다.
2. 병합 버튼에서 `POST /api/merge`로 순서·텍스트·비율·letterbox·키워드를 보낸다. `VideoMerger`를 만들고, `run()`은 별도 스레드에서 돌린다. 응답은 “시작됨”과 예상 출력 파일명만 바로 온다. 끝날 때까지 기다리지 않는다.
3. 스레드 안에서 각 영상을 목표 비율로 재인코딩하고(필요하면 오버레이 PNG), concat으로 `videos/final/`에 합친다.
4. 홈의 `/api/status`를 몇 초마다 폴링해서 final 폴더에 새 파일이 생겼는지 본다.

**AI 프롬프트**

1. `POST /api/ai/generate-prompt`에 topic(과 UI의 is_asmr 플래그)을 보낸다.
2. `PromptGenerator`가 OpenAI에 시스템+유저 메시지를 보내고 JSON을 받는다. 실패하면 최대 3번 재시도하고, 그래도 안 되면 fallback 문구를 준다.
3. 브라우저가 video_prompt / hook_caption / hashtags를 화면에 보여 주고, 복사 버튼으로 가져간다.

참고: UI에서 보낸 `is_asmr`은 `app.py`에서 꺼내 두기만 하고 `generate_prompt()`에 넘기지 않는다. 그래서 지금은 항상 ASMR 전용 경로다. (최종정리에 더 적음)
