# 6. 사용방법

README에 있는 `./start_servers.sh`나 포트 8000 AI 클리핑 안내는 지금 코드랑 안 맞는다. 아래만 보면 된다.

## 필요한 것

Python 3, PATH에 잡힌 FFmpeg(`ffmpeg` / `ffprobe`), 프롬프트 쓸 거면 OpenAI API 키.

## 설치·실행

```bash
cd video-merger
pip3 install -r requirements.txt
cp env.example .env   # OPENAI_API_KEY 넣기
python3 app.py
```

브라우저에서 `http://localhost:5001`.

루트 `./go`는 쓰지 말 것. 지워 버린 FastAPI를 켜려고 해서 실패한다. Docker도 루트 requirements가 없어서 README만 보고 돌리기 어렵다.

5001이 이미 쓰이고 있으면 Flask가 안 뜬다. 다른 프로세스 끄거나 포트를 바꿔야 한다. `ffmpeg: command not found` 나오면 PATH부터 확인하고, Mac이면 `brew install ffmpeg`.

## 쓰는 법

Merge Videos에서 mp4 올리고 순서·텍스트·비율·letterbox 정한 다음 병합. 결과물은 `videos/final/`. AI Prompt는 주제 넣고 생성한 뒤 복사하면 된다.

웹 없이 병합만 하려면 `videos/raw/`에 mp4 넣고:

```bash
cd video-merger
python3 -m merge.merge
```

## 알려진 문제

텍스트 오버레이 폰트가 macOS 경로로 박혀 있어서, 다른 OS에서는 글자나 이모지가 깨질 수 있다. 병합은 끝나면 알림이 없고 홈 화면이 파일을 다시 읽을 때까지 기다려야 한다.
