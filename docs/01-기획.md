## 이 프로젝트로 뭘 만들려고 했는지

유명한 유튜브 영상에서 바이럴한 구간만 자동으로 잘라 SNS에 올리는 흐름을 만들고 싶었다. 그와 별개로, 그즈음 나온 nano banana pro로 영상·이미지 프롬프트를 제대로 써 보고 싶었고, 세계 여행하는 고양이들 컨셉의 가상 인플루언서 계정도 운영해 보고 싶어서 시작했다.

도구로 보면 `clips` / `video-merger`는 짧은 영상을 쇼츠용으로 합치고, 주제만 넣으면 AI 영상·이미지용 프롬프트·훅·해시태그를 뽑아 주는 웹앱이다. 초기에는 YouTube를 받아 AI로 클립을 자르는 기능까지 들어 있었다. 2026-01-31에 `ai_clipping/`이랑 AI 클립 페이지를 빼 버렸고, 지금은 그 기능이 없다. 루트 README만 예전 설명을 그대로 두고 있다.

## 해결하려던 문제 또는 동기

SNS용 클립을 손으로 고르고 자르는 게 귀찮아서, AI로 바이럴 구간을 자동 추출한 뒤 올리는 운영을 해보고 싶었다. 프롬프트 쪽은 nano banana pro를 제대로 다뤄 보고 싶다는 호기심이 컸고, meow(고양이 여행) 타입은 가상 인플루언서용 이미지 프롬프트를 뽑으려고 넣었다.

## 목표 기능 목록 (계획 단계 관점)

처음에 잡고 있던 것들. 다 끝까지 가진 건 아니다.

여러 MP4를 순서대로 하나로 붙이는 건 맨 처음부터 핵심이었다. 웹에서 올리고 순서 바꾸고 미리보는 UI, 영상 위 텍스트, 4:5·9:16 같은 출력 비율도 같이 생각했다. 주제만 넣으면 영문 프롬프트·훅·해시태그가 나오게 하는 생성기도 목표에 들어 있었고, ASMR이나 meow처럼 스타일별로 프롬프트를 가르는 것도 계획에 있었다.

YouTube 다운로드 → STT → 구간 선택 → 클립·자막까지는 초기에 실제로 넣었다가 나중에 통째로 빼 버렸다. meow(고양이 여행) 타입도 README에 남아 있지만, 후반에는 ASMR 먹방 쪽으로만 좁혀졌다.

| 목표 | 비고 |
|------|------|
| MP4 여러 개 순서대로 병합 | 처음부터 필수 |
| 웹에서 업로드·순서·미리보기 | UI로 쓰려고 |
| 텍스트 오버레이 | 있으면 좋음 |
| 출력 비율 선택 | 쇼츠용으로 |
| 주제 → 프롬프트/훅/해시태그 | nano banana pro 쓸 때 필요 |
| ASMR / meow 등 타입 분기 | meow는 고양이 계정용 |
| YouTube → STT → 클립·자막 | 초기에 넣었다가 삭제함 |
